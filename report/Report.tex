\abstract{ This project focuses on analyzing heart-rate synchrony across individuals to verify if it's modulated by attentional state while watching educational videos.

The goal is therefore to replicate a couple of results from Pérez et al. (2021)~\cite{perez2021} using data from a newer dataset: the Brain, Body and Behavior Dataset (BBBD)~\cite{bbbd}.

To achieve this, heart-rate fluctuations were extracted from raw ECG recordings and compared across subjects using ISC-HR (inter-subject correlation of heart-rate).

A hypothesis test with a FDR correction is used to establish statistical significance of the obtained results. ISC-HR is then compared between attentive and distracted conditions through a paired statistical test across all five stimuli.

Hypothesis test and descriptive statistics are employed to analyze synchrony patterns and to detect the effect of attention across stimuli.

The results provide a statistically grounded replication of ISC-HR modulation by attention, discussed in relation to the original paper's finding on which this project is based.

 }

\section{Introduction}\label{sec1}

Heart rate is often treated as a purely autonomic signal, reflecting internal physiological states such as arousal or stress.\\
A recent study suggest that heart-rate fluctuations can be driven by external stimuli.
When multiple individuals are exposed to the same narrative content, their heart rates tend to fluctuate in a similar way.\\
This phenomenon is known as inter-subject correlation of heart-rate (ISC-HR).\\

Pérez et al. (2021)~\cite{perez2021} proposed that these heart-rate fluctuations are modulated by conscious, attentive processing of the stimulus. \\

This project aims to replicate two of the main results reported by the analyzed paper.
\begin{itemize}
\item ISC-HR is statistically significant across subjects exposed to the same stimulus (R1).
\item Synchrony is modulated by attentional state, being higher when subjects are attentive than when they are distracted (R2).
\end{itemize}


This work uses data from the Brain, Body and Behavior Dataset (BBBD)~\cite{bbbd}, which is a more recent dataset that includes similar experiments to the original study.

\section{Related Work}\label{Sec2}

The original paper~\cite{perez2021} computes ISC-HR by correlating each subject's instantaneous heart-rate fluctuations against the rest of the group, averaging the resulting pairwise correlations in Fisher-Z space, and testing significance via a circular-shift permutation procedure with False Discovery Rate (FDR) correction.
The study reports three main findings across four experiments.\\


The first one (R1) shows that heart-rate fluctuations synchronize across subjects listening to the same auditory narrative, with 17 of 27 subjects having statistically significant ISC-HR.\\

The second result (R2) shows this synchrony is systematically higher when subjects attend to a stimulus than when they are distracted.\\

The third result (R3) shows that ISC-HR predicts subsequent memory recall performance for the narrative content, suggesting that the measure reflects conscious engagement rather than an autonomic response to sensory input.\\

The fourth experiment applies ISC-HR to patients with disorders of consciousness, showing reduced synchrony relative to healthy controls and framing ISC-HR as a potential prognostic marker in a clinical setting.

As already anticipated, this project replicates only R1 and R2 using an experiment equivalent to the original study's experiment 2.\\

\section{Dataset}\label{sec3}

This project uses Experiment 2 of the BBBD dataset~\cite{bbbd}, which contains recordings of ECG, EEG, eye-tracking, and respiration during educational video viewing.\\

In experiment 2, 31 subjects watch five educational videos, each one viewed twice by the same subject: attentively the first time, distracted by performing a secondary task (silently counting backward) the second time. The extracted data have a sampling frequency 128Hz with a total duration close to 3 minutes of ECG signals.

BBBD's data descriptor~\cite{bbbd} explicitly states that the ECG data provided for this experiment are not newly collected, but are the same recordings originally published in Pérez et al., 2021~\cite{perez2021}.\\

ECG preprocessing documentation~\cite{bbbd} states that R-wave peaks were detected automatically and then manually corrected.
This project instead detects R-peaks directly from the raw ECG signal using an automated procedure, without using BBBD's provided peak timestamps and without manual review.\\
This choice was made in order to reproduce and understand the original study's methodology.\\

Not every subject has a usable recording for every (subject, session, stimulus) combination. Missing files are skipped automatically, so the number of subjects analyzed varies slightly across stimuli and conditions.

This chapter describes the full process from raw ECG signals to the statistical tests used to replicate R1 and R2.\\
Most of the process follows the methodology described in the original paper.

\subsection{Signal preprocessing}\label{subsec1}

Raw ECG signals are first high-pass filtered to remove baseline drift, then a notch filter is used to suppress power-line interference.
The first high-pass filter used a 0.5 Hz cutoff, in order to preserve the faster fluctuations corresponding to heartbeats while attenuating baseline drift.

The notch filter targets 60 Hz, which is the frequency of electrical interference from the power supply. 
Considering the dataset's 128 Hz sampling rate, the Nyquist limit is therefore 64 Hz. This places 60 Hz close to this edge. Thus the effect of the second filter is marginal.\\

R-peaks are detected by using an adaptive amplitude threshold.
The chosen value is $3\times$ standard deviations of the filtered signal. This is combined with a 0.3s temporal distance between consecutive detections.\\

Instantaneous heart rate was computed as the inverse of consecutive R-R intervals $\frac{60}{RR}$ (BPM), where RR is the time interval between two consecutive R-peaks. Then it's resampled onto a common 4Hz grid via interpolation to allow comparison across subjects. \\

This last step is made because instantaneous HR series have one value per heartbeat and themselves do not occur at fixed intervals. The requirement for the next step which is computing a Pearson correlation between the HR signals of different subjects requires vectors of equal length, aligned on the same time points.\\

Subjects whose mean heart rate fell outside a plausible range (40-160 BPM) were automatically excluded from further analysis in order to improve the quality of the results.

\subsection{ISC-HR computation}\label{subsec2}

In order to compute ISC-HR, all subjects' interpolated HR series are truncated to their shortest common length and arranged into a matrix of pairwise Pearson correlations.\\

Each subject's ISC-HR is computed as follows:
\begin{equation}
\text{ISC-HR}_i = \tanh\left(\frac{1}{N-1}\sum_{j \neq i} \text{arctanh}(r_{ij})\right)
\end{equation}
where $r_{ij}$ is the Pearson correlation between subject $i$ and subject $j$, and self-correlation ($j=i$) is excluded. Correlations are first transformed with the Fisher-Z transform ($\text{arctanh}$) before averaging. The inverse transform ($\tanh$) then maps the average back onto the original correlation scale.



\subsection{Hypothesis test}\label{subsec3}

In order to establish statistical significance of each subject's ISC-HR, a circular-shift permutation test is computed.\\

The subject's HR series is circularly shifted by a random amount and re-correlated against the reference group. This is repeated $B=10{.}000$ times to build a null distribution, which is the set of ISC-HR values that subject would obtain purely by chance.\\

The p-value is the fraction of the $B$ null values that are at least as large as the subject's real observed ISC-HR. It measures how surprising the observed value is under the assumption of no true synchrony.\\
A small p-value means it would be rare, by chance alone, to obtain a value this large.

In practice, this fraction is computed as:
\begin{equation}
p = \frac{1 + \text{count}}{B + 1}
\end{equation}
where $\text{count}$ is the number of null values at least as large as the observed ISC-HR. The reason: if the observed value exceeds all $B$ permutations, the plain proportion returns exactly $p=0$, incorrectly claiming chance could never produce such a result. The $+1$ correction bounds the smallest reportable p-value at $\frac{1}{B+1}$ instead.\\

Benjamini-Hochberg FDR correction is then applied across all subjects within each combination.\\

\subsection{Attention modulation}\label{subsec4}


Following Pérez et. al, 2021~\cite{perez2021} STAR Methods, ISC-HR for the distracted condition was computed against a fixed reference: each distracted subject's series was correlated against the entire attentive group, rather than against other distracted subjects.\\

For each of the five stimuli, the attentive-minus-distracted ISC-HR difference was computed per subject (restricted to subjects with a usable recording in both conditions). A Shapiro-Wilk normality test was run once on the pooled differences across all five stimuli to decide between a paired $t$-test and a Wilcoxon signed-rank test; the chosen test was then applied uniformly to each stimulus individually.\\
The chosen test is then applied uniformly to each stimulus individually, testing whether the difference between the attentive and distracted ISC-HR is significantly different from zero. \\
A significant result ($p<0.05$) for a given stimulus indicates that attention modulates ISC-HR for that stimulus, addressing R2.

\subsection{Implementation choices}\label{subsec5}

Several parameters were not specified in the original paper and required to make implementation choices.\\

\begin{itemize}
\item The amplitude threshold for heartbeat peak detection.
\item Physiological HR range used for quality control.
\item Interpolation method for resampling.
\end{itemize}

Two other choices were also made for simplicity:

\begin{itemize}
\item Regarding R1, ISC-HR in the distracted condition is computed within-group (distracted subjects correlated against each other) rather than using the attentive-referenced method. The latter is used specifically to replicate R2, where the attentive-distracted comparison requires it.
\item This project does not use the original paper's ANOVA method, which tests both factors (attention $\times$ stimulus) and their interaction together in a single model. R2 instead uses five separate paired tests, one per stimulus[~\ref{subsec4}].
\end{itemize}
